# 车牌通 · 全国车牌速记（安卓轻量版）

一个**完全离线、免安装、可装到手机主屏**的 PWA 应用，帮你轻松记住全国 34 个省级行政区、348 个城市的车牌号，并附带每个城市的**人文历史 / 风景地标 / 美食特产 / 记忆点**。

---

## 📦 安装包（APK）

已打包成可直接安装的安卓应用：**`车牌通.apk`**（约 2.3 MB，Android 5.0+，内置全部离线数据、地图与图标）。

**安装**：把 `车牌通.apk` 传到手机 → 点击安装 → 若提示「未知来源」选择允许（自签名、未上应用商店，属正常提示）。装好后桌面出现「车牌通」图标，点开即可全屏离线使用。

**重新打包**：在 `android/` 目录运行 `powershell -ExecutionPolicy Bypass -File build.ps1`（需先有 SDK，见 `android/download_sdk.py`）。

| 模块 | 说明 |

## 📱 怎么在安卓手机上用

### 方式一：直接打开（最快，先体验）
把整个 `chepai-app` 文件夹拷到手机，用手机浏览器或文件管理器打开 `index.html` 即可用（核心功能全部正常）。

### 方式二：安装成「主屏 App」（推荐，全屏 + 离线 + 图标）
PWA 需要 **https 或 localhost** 环境，任选其一：

**A. 部署到免费静态托管**（最省心，一次部署永久可用）
- [GitHub Pages](https://pages.github.com) / [Vercel](https://vercel.com) / [Netlify](https://netlify.com) 任选一个，把文件夹拖上去即可得到一个网址。
- 手机浏览器打开该网址 → 浏览器菜单（⋮）→ **「添加到主屏幕 / 安装应用」** → 桌面出现「车牌通」图标，点开即全屏离线运行。

**B. 电脑局域网临时预览**
在电脑上、本文件夹内运行下面任一命令：
```bash
python -m http.server 8080        # 或
npx http-server -p 8080
```
手机与电脑连同一 WiFi，手机浏览器访问 `http://电脑IP:8080`，再「添加到主屏幕」。

## 🧠 记忆心法（内置在数据里）

背车牌不用死记，App 每个城市都给了 4 个锚点：
- 🏛️ **人文历史** — 如「鲁A 济南·泉城」「豫B 开封·八朝古都」
- 🏔️ **风景地标** — 如「苏E 苏州·拙政园」「桂C 桂林·漓江」
- 🍜 **美食特产** — 如「粤B 深圳·光明乳鸽」「湘A 长沙·臭豆腐」
- 💡 **记忆点** — 谐音/联想，如「浙A 杭州 = Ali(阿里)」「鲁B 青岛 = Beer(啤酒)」「苏E 苏州 = 东方之门」

**推荐学习路径**：直辖市 → 省会 A 牌 → 家乡省 → 按大区逐个点亮 → 全图混合练习。

## 📁 文件结构

```
chepai-app/
├── 车牌通.apk            已签名的安卓安装包
├── index.html            应用界面
├── style.css             样式
├── manifest.json         PWA 配置
├── sw.js                 离线缓存
├── icon-192.png / icon-512.png / avatar.png  图标与头像
├── js/
│   ├── data.js           全国 348 城车牌 + 城市特色数据
│   ├── app.js            全部交互逻辑
│   ├── echarts.min.js    图表库（离线内置）
│   └── china_city.js     地级市 GeoJSON（地图）
└── android/              安卓工程（WebView 壳 + 打包脚本；SDK 用 download_sdk.py 下载）
```

> 数据来源为公开车牌规则；部分行政区划有调整（如莱芜已并入济南、港澳使用独立字头车牌），已在数据中标注。
